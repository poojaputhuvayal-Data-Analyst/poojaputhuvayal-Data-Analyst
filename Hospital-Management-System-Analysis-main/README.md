# 🏥 Hospital Management System Analysis Dashboard

An end-to-end analytics project using **SQL** and **Power BI** to analyze and visualize the performance of a hospital's appointment system. This project identifies key operational issues such as appointment cancellations, departmental load, doctor performance, patient demographics, and payment patterns—enabling data-driven decisions to improve efficiency and patient care.

## 🎯 Objective

Transform raw hospital data into a powerful Power BI dashboard that empowers hospital administrators to:

- Identify high-performing doctors and departments
- Reduce appointment cancellations
- Monitor seasonal and demographic trends
- Improve financial visibility via payment tracking
- Optimize staff allocation and patient services

---

## 🚀 Project Features

✅ **Interactive Dashboard with Filters & Drillthroughs**  
✅ **KPIs** – Total Appointments, Avg. Patient Age, Cancellation Rate  
✅ **Doctor-wise & Department-wise Performance Pages**  
✅ **Monthly Trends & Gender-based Analysis**  
✅ **Payment Mode Breakdown**  
✅ **Custom Tooltips & Bookmark Navigation**  
✅ **Advanced DAX for time intelligence & metrics**

---

## 🛠️ Tools & Technologies

- **SQL**: Data extraction, joins, cleaning
- **Power BI**: Visual storytelling, DAX, bookmarks, interactivity
- **DAX**: Custom KPIs, % calculations, date handling
- **Excel**: Initial data wrangling

## 📊 Insights & Business Value

| 🔍 Insight | 📈 Business Value |
|-----------|------------------|
| **10% Appointment Cancellations** | Signals need for automated reminders & schedule optimization |
| **Dr. Peter Peterson (Neurology) Top Performer** | Role model for efficiency, used to improve others' scheduling |
| **Cardiology & Pediatrics - High Load** | Need for better staffing, equipment allocation in peak departments |
| **Cash & Insurance – Dominant Payment Modes** | Focus for payment gateway integrations & insurance partnerships |
| **Avg Age: 46, Equal Gender Split** | Supports targeted healthcare packages and campaigns |

➡️ **Result**: A Interactive Report that gives decision-makers actionable insights across patient care, doctor performance, and operations.
